## Minard Siobal | Portfolio v2

This is my personal portfolio website, rebuilt from scratch in TypeScript to showcase my projects, skills, and the technologies I use as a full stack developer.

#### 🔗 [Live Demo](https://siobaldev.vercel.app/)
---
### Technology Used:

- Framework: Next.js
- Language: TypeScript
- Styling: Tailwind CSS
- Animation: Motion
- Forms: React Hook Form + Zod
- Email: Resend

### Features

- Fully responsive design for seamless navigation on any device
- Dark mode
- Scroll-triggered animations throughout
- Halftone shader effect on project previews
- Functional contact form powered by Resend
